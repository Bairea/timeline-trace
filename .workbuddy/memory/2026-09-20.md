## 已定关键决策

- 记录交互：B2 自由画 + 精确输入为主，拖动为微调（用户明确选 B2 而非 B1 吸附）。
- 命中判定：**时间重叠度自动算**，不做手工勾选（用户确认「自动判定够用」）。
- 硬需求：导出每天每段的精确时间分配（CSV UTF-8 BOM / XLSX 多 sheet）。
- 栈：Python FastAPI + 原生 JS 单页 + 单 SQLite；主要在电脑上用；白天随手记。
- 存储：时间一律存分钟数整数；跨零点块单根、归属起始日。
- 删除：可视化块上可删，真删除 + 5 秒撤销，落库保留 `deleted_at` 软删除标记。
- status 固定四档：aligned / offset / unrecorded / unplanned（`short` 已归并入 offset）。
- 部署：云服务器公网 IP **无域名**，用户选定 **方案 A 自签证书**（已知风险：无法防 MITM，文档已记录）。必做：访问口令 + 每日备份 + 不暴露 8000 端口。
- 明确不做：多用户、移动 App、自动追踪、任务管理、推送提醒。
